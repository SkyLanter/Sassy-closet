# Gửi đồ cho Sassy Closet 💕

Mở **link OneDrive Boss đã share** (folder **From GF**). Em tự thả ảnh + điền mẫu. Không cần chờ ai paste.

## Tiếng Việt (xài điện thoại được)

1. Mở link Boss gửi → folder **From GF**.
2. Tạo folder nhỏ: `ngày_tên-đồ` (vd `2026-09-05_vay-hoa`).
3. Thả ảnh vào folder đó.
4. Copy file `INTAKE_TEMPLATE.txt` vào folder, điền những gì em biết. Không biết thì bỏ trống.
5. **Đừng tự đặt mã** (AO / QU / VA / AK / GI / PK / SET). Stock đọc Dashboard rồi Boss gán.
6. Có link Taobao / shop thì dán vào `source`. Không có link thì ghi `no_source: yes`.
7. Size **Á châu + cm** (vd `M 88cm`). Không cần size Mỹ.

**Looking** = đang xem / ứng viên → Wishlist, **chưa lên Square**.  
**Bought** = em đã mua hoặc đã nhận → vẫn **chưa lên Square**. Chưa có mã thì Boss hỏi Stock. Có mã (Boss gán) mới vào Official (bản làm việc) — vẫn chưa Save Square.

Slack `#shop-intake` chỉ khi OneDrive khó. Boss paste / email là dự phòng. **Không** dùng Messenger. Dial Bot là máy gọi yêu, không phải chỗ gửi đồ.

*Sau này nếu OneDrive rối, shop có thể thêm Microsoft Form. Chưa làm Form bây giờ.*

Cảm ơn em 💗

## Boss / Kit only (do not send Graph webUrl)

If the folder link **404s**, it is probably the raw Graph `webUrl`:

`https://onedrive.live.com?cid=…&id=…` (no slash after `.com`, raw `!`).

That shape often 404s. **Do not** hand it to GF.

Send GF a **Share → Can edit → Copy link** URL (usually `1drv.ms`).  
Canonical browse + encoding: [`LINKING.md`](./LINKING.md). Helper: `python3 excel-kit/sot/onedrive_from_gf_link.py --help`.
