# Photos

Cute Excel (pink books, emoji covers, embedded stickers) is **retired**.

Hub path on OneDrive (Build lands later):

`Documents/Sassy Closet/Photos/{MA}/001.jpg`

Excel stores that folder in `photo_folder` only. Never embed images.

`kit.sh save` syncs live `GET https://sassy-closet.vercel.app/api/photos/{ma}/001.jpg…` into `out/Photos/{ma}/` for mãs that appear on the live export. It does not invent a mã to name a folder.

Mã letters: A áo · Q quần · V váy · K áo khoác · G giày · B túi · P phụ kiện · S set · O khác · H tóc · J trang sức.

A02 was renamed to P02 (not P05). P02 and P05 are separate. Do not leave an A02 photo folder as if it were still a live mã.
